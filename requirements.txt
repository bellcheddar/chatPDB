# vina: pip install requires Boost, and stock Homebrew boost (1.90) fails to compile against
# vina 1.2.7's C++ code (missing std:: type_traits includes -- a real boost-1.90/vina
# incompatibility, not a local misconfiguration). Fix: `brew install boost@1.85`, symlink its
# `-mt`-suffixed libs to unsuffixed names (`ln -s libboost_thread-mt.dylib libboost_thread.dylib`
# etc. in /opt/homebrew/opt/boost@1.85/lib/), then:
#   CONDA_DEFAULT_ENV=fake CONDA_PREFIX=/opt/homebrew/opt/boost@1.85 pip install vina
# (vina's setup.py only searches a conda env, /usr/local/include, or /usr/include for Boost --
# spoofing CONDA_PREFIX is the only way to point it at Homebrew's non-standard /opt/homebrew path
# without sudo-writing into /usr/local, which is root-owned on Apple Silicon.)
